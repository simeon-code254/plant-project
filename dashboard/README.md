# Crop Disease Detection Dashboard

A Streamlit dashboard for the multi-crop PlantVillage disease classification project.

## 1. Expected project layout

Keep this dashboard alongside the notebooks' `models/` and `evaluation/` folders:

```text
crop-disease-detection/
├── app/
│   └── app.py
├── models/
│   ├── custom_cnn.keras
│   ├── mobilenetv2.keras
│   ├── resnet50.keras
│   └── class_names.json
├── evaluation/
│   ├── custom_cnn_metrics.json
│   ├── mobilenetv2_metrics.json
│   └── resnet50_metrics.json
└── requirements.txt
```

The model and metric files are generated by running the Jupyter notebooks. They are not included because they depend on your dataset and actual training runs.

## 2. Install dependencies

From the project root:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

Use a TensorFlow/Python combination supported by your operating system. If local TensorFlow installation is difficult, train in Google Colab, download the generated `.keras` and JSON files, and place them in the folders above.

## 4. Dashboard pages

- Overview: project introduction and setup status.
- Disease Detection: upload a JPG/JPEG/PNG leaf image, select an available trained model and view top predictions.
- Model Performance: compare measured test metrics and inspect confusion matrices.
- About: research methodology, technologies and limitations.

## 5. Important

- Run the model notebooks first; this dashboard does not train models.
- The class mapping file must match the output order used during training.
- All models must use 224 × 224 RGB input as configured in the supplied notebooks.
- The dashboard expects the saved models to contain their model-specific preprocessing layers, as in the notebooks.
- The confidence shown is a softmax score, not a calibrated probability.
- PlantVillage test performance does not guarantee performance on real farm images.
